# ⚡ БЫСТРЫЙ СТАРТ (2 минуты)

## Получите Database Password

1. Откройте: https://supabase.com/dashboard/project/jljcchkpowprgqslxhac/settings/database
2. В разделе **"Connection string"** найдите **"URI"**
3. Кликните **"Reset database password"** (если нужно)
4. Скопируйте полный Connection String

Он будет выглядеть так:
```
postgresql://postgres.jljcchkpowprgqslxhac:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:6543/postgres
```

## Обновите .env

Откройте файл `.env` в корне проекта и замените:

```bash
# Было:
DATABASE_URL=postgresql://postgres.jljcchkpowprgqslxhac:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:6543/postgres

# Станет (вставьте ваш реальный connection string):
DATABASE_URL=postgresql://postgres.jljcchkpowprgqslxhac:ваш_пароль_здесь@aws-0-us-east-1.pooler.supabase.com:6543/postgres
```

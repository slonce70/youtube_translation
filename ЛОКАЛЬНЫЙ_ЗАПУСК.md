## Установка tusd (для загрузки файлов)

### Вариант А: Скачать бинарник

```bash
# 1. Скачайте для macOS
curl -L https://github.com/tus/tusd/releases/download/v2.5.0/tusd_darwin_arm64.tar.gz -o tusd.tar.gz

# 2. Распакуйте
tar -xzf tusd.tar.gz

# 3. Переместите
sudo mv tusd_darwin_arm64/tusd /usr/local/bin/

# 4. Проверьте
tusd --version
```

### Вариант Б: Собрать из исходников

```bash
# Если есть Go
go install github.com/tus/tusd/v2/cmd/tusd@latest
```

### Вариант В: Запустить через Docker (только tusd)

```bash
docker run -d \
  -p 8080:8080 \
  -v $(pwd)/uploads:/data \
  tusproject/tusd:latest \
  --hooks-http=http://host.docker.internal:8000/api/assets/webhook
```

## Частые проблемы

### "Port 8000 already in use"
```bash
# Найдите процесс
lsof -ti:8000

# Убейте его
kill -9 $(lsof -ti:8000)
```

### "Port 3000 already in use"
```bash
kill -9 $(lsof -ti:3000)
```

### "Module not found"
```bash
# Backend
cd backend
python3 -m pip install -r requirements.txt

# Frontend
cd frontend
npm install
```

### "Cannot connect to Supabase"
Проверьте `.env` файл:
```bash
cat .env | grep SUPABASE
```

Должны быть заполнены:
- SUPABASE_URL
- SUPABASE_KEY
- SUPABASE_JWT_SECRET

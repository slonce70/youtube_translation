# Design Archive

Ця директорія містить неканонічні design/mockup артефакти, які використовувались під час дослідження та ітерацій над landing/admin UX.

## Що тут зберігається

- standalone HTML mockups
- screenshot exports
- design review PNG

## Правило для V0 baseline

- ці файли **не входять** у shipping/runtime path
- локальний bootstrap, тести і rehearsal не повинні залежати від них
- якщо потрібні нові дизайн-референси, додавайте їх сюди або в піддиректорії `archive/`, а не в корінь репозиторію

# Loopcast — UX-аудит + направления редизайна (2026-06-21)

Глубокий UX-аудит внешней (лендинг) и внутренней (операторская панель) поверхностей
+ синтез конкурентного/эталонного ресёрча + 5 прототипов титульной и 5 прототипов панели.
Прототипы отрендерены в чате (visualize-виджеты) для сравнения и выбора направления.

Продуктовая рамка (ключевой вывод ресёрча панели): **Loopcast — это операционный пульт
для необслуживаемой инфраструктуры, а не creator-tool.** Пользователь запускает эфир и
уходит на дни. Главная задача панели — «скажи с одного взгляда, живы ли мои оплаченные
эфиры, и дай быстро починить сломанный». Это сближает Loopcast с Mux + Cloudflare Stream +
Grafana/Datadog + status-page, а не с Twitch/OBS/YouTube Studio.

---

## 1. Аудит — что есть сейчас

### Внешняя (лендинг, `components/landing/HomePageClient.tsx` + `loopcast.css`)
База сильная: правильная структура секций (hero → ticker → «отдавать ли доступ к каналу» →
4 шага → демо → bento-фичи → uptime-пруф → отзывы → FAQ → цены → финальный CTA), единый
indigo-акцент `#5b6cff`, тёмный editorial-тон, 3D-глобус, хорошая копия.

Проблемы:
- **Нет «продукт-как-герой»** — главный недожатый конвертер. Эталоны (Linear, Railway,
  Restream) и прямые конкуренты показывают живой продукт; у нас абстрактный глобус. Для
  продукта «оно крутится без тебя» нужен тикающий аптайм-таймер + счётчик зрителей + now-playing.
- **3D-глобус конкурирует с заголовком** — текст ложится поверх «шумной» wireframe-сферы,
  страдает читаемость + LCP/перф (Three.js в герое).
- **Возражение №1 категории — «комп может быть выключен» — не вынесено ударно** в герой
  (спрятано в баннере ниже). Все серьёзные конкуренты держат это на первом экране.
- **СКРОЛЛ ЛЕНДИНГА ЗАЛОЧЕН в dev-сборке** (прокрутка пиннится на ~22px; не CSS scroll-snap,
  похоже JS/эффект). КРИТИЧНО проверить в prod-сборке — если воспроизводится, это блокер.
- Глифы `▷`/`→` как текст в кнопках (рассинхрон с lucide в панели); слабый соц-пруф
  (эмодзи-аватары, шаблонные отзывы), нет логотипов/чисел над сгибом.

### Внутренняя (панель, `app/dashboard/*`)
Чистая SIGNAL-система: sidebar + topbar + ⌘K, stat-strip, health-spine, хорошие empty states.

Реальные баги (под фикс независимо от редизайна):
- **`/dashboard/plans`: в UI протекают DEV-заметки** — подпись «реалізована як hybrid:
  prototype shell + поточна pricing логіка» и бейдж «Hybrid release». Источник:
  `messages/{uk,ru,en}/plans.json` ключи `releaseBadge`, `description`. Это видит клиент.
- **`/dashboard/plans`: дубль бейджа «Поточний»** на карточке Free.
- **`/dashboard/library`: «0 Bytes використано з 3 ГБ»** при наличии файла 187 КБ (баг
  счётчика storage) + пустой thumbnail без постер-кадра.
- **`/dashboard/channels`: жаргон «RTMPS» в заголовке страницы**, «Канали» дублируется
  (page title + card header), много пустоты.
- **Нет настоящего overview/home** — вход = «Трансляції», stat-cards (0 / 0/1 / 1/1 / 0)
  мало-информативны: нет трендов, нет real-time-пульса, нет «сначала сломанные».
- Для оператора с многими стримами **нет list/table-режима и density-toggle** — везде карточки.

## 2. Синтез ресёрча (конкуренты + эталоны)

### Лендинг
Рыночный зазор: у прямых конкурентов (Gyre, Upstream, Looping Stream) правильный продукт, но
любительские страницы; у мультистрим-гигантов (Restream, Castr, OneStream) красивые страницы,
но 24/7 — галочка. **Loopcast выигрывает как первый 24/7-loop-инструмент с лендингом уровня
Linear/Vercel + острым углом.** Угол «комп может быть выключен» — определяющее возражение
категории; должен быть на первом экране. Рецепт: dark-first + один indigo-glow как «свет, а не
обои» (дисциплина Stripe) + продукт-как-герой с живым аптаймом + bento-сетка фич + моно-акценты.

### Панель (8 ключевых паттернов)
1. Разделить ingest-здоровье и delivery-здоровье; **вести ingest-ом** (encoder→YouTube жив,
   битрейт у цели, FPS стабилен), зрители — вторично (Mux).
2. **Health-пилюля из 4 состояний с порогами + словом** (Healthy/Degraded/Poor/Offline →
   зелёный/янтарь/красный/серый), иконка+слово (не только цвет), «Poor» объясняет почему.
3. **Дом = список работающих эфиров + спокойная глобальная строка здоровья**; тренды — на
   отдельную Usage-поверхность (Render/Railway/PagerDuty).
4. **Сортировка «сначала сломанные»** по умолчанию; здоровые — визуально тише (dark-NOC).
5. **Sparkline «ровная линия = здорово» + линия цели** на каждой карточке (Cloudflare/Twitch).
6. **Лента событий** (connected/reconnecting/auto-restarted/stopped) — главный «жив ли» сигнал
   и аудит «что было в 3 ночи» (Mux Events / Resend timeline).
7. **Lifecycle-контролы Start/Stop/Restart**, state-gated, с переходным состоянием
   («Starting…»), optimistic UI; авто-восстановление до обращения к человеку (Railway/Streamlabs).
8. **Auto-restart как фича, а не скрыто** («авто-перезапуск ×2 за сутки»). + ⌘K везде,
   type-to-confirm на Stop работающего эфира, virtualized pin-to-bottom лог, dark-first
   luminance-elevation, tabular-nums на всех числах.

## 3. Прототипы (отрендерены в чате)

### Титульная (5)
1. **Control Room** — надёжность; тёмная консоль-герой с тикающим аптаймом (NOC-эстетика).
2. **Закрий ноутбук** — удобство; светлый/тёплый, метафора «закрыл ноут → эфир в облаке → YouTube».
3. **Always-On Revenue** — монетизация; крупные цифры watch-time/RPM, Stripe-glow.
4. **The Loop** — премиум/крафт; одна aurora + сигнал-орб, гигантская типографика, минимализм.
5. **Bento / Free to Start** — низкий порог; bento-сетка + бесплатный тариф на первом экране.

### Панель (5)
1. **Mission Control** — overview-дом: глобальная строка здоровья + сетка плиток, сломанные сверху + лента.
2. **Stream Cockpit** — Mux-clean: диагностическая страница одного эфира (превью + ingest-график + события).
3. **Linear-fast console** — плотная клавиатурная таблица, ⌘K, j/k, optimistic, is:/health: грамматика.
4. **Status-page calm** — большой баннер здоровья + 90-дневные полосы аптайма, storytelling надёжности.
5. **Railway canvas** — пространственный граф Файл → Эфир → Канал со статус-бейджами.

## 4. Рекомендация

- **Лендинг:** **Control Room** как каркас + угол «Закрий ноутбук» в копии героя
  (продукт-как-герой с живым аптаймом — самый сильный конвертер; убрать тяжёлый глобус из-за текста).
  Bento-сетку (#5) использовать ниже для секции фич.
- **Панель:** **Mission Control** как новый дом (overview) + **Stream Cockpit** как детальная
  страница эфира. **Linear-fast** — как «плотный» режим списка для операторов с многими стримами
  (density toggle). Status-page-полосы аптайма (#4) встроить как вкладку «Надёжность».
- **Сначала починить баги** из §1 (dev-note leak, дубль бейджа, storage-счётчик, RTMPS-жаргон,
  проверить scroll-lock) — дёшево и сразу повышает доверие.

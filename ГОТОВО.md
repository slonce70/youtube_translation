**Создайте `frontend/.env.local`:**


## 💡 Первые шаги после запуска

### 1. Загрузите тестовое видео

```bash
# Конвертируйте видео в правильный формат:
ffmpeg -i input.mp4 \
  -c:v libx264 \
  -c:a aac \
  -pix_fmt yuv420p \
  -g 60 \
  -profile:v high \
  -level 4.1 \
  output.mp4
```

Требования:
- Video codec: H.264
- Audio codec: AAC
- Pixel format: yuv420p
- GOP size: ≤ 2 sec (60 frames @ 30fps)

### 2. Создайте первый плейлист

1. Assets → Upload Asset → выберите видео
2. Playlists → Create Playlist
3. Добавьте загруженные видео
4. Включите "Loop" для 24/7

### 3. Добавьте YouTube канал

1. Destinations → Add Destination
2. Введите название и Stream Key
3. URL по умолчанию: `rtmps://a.rtmp.youtube.com/live2`

### 4. Запустите стрим!

1. Streams → Create Stream
2. Выберите плейлист и destination(s)
3. Start → View Logs → проверьте на YouTube

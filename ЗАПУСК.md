- ✅ **Frontend** (Next.js 15 + React 19) - 100% готов

## 📋 Что нужно для запуска

### 1. Необходимое ПО

На вашем сервере/компьютере должно быть установлено:

```bash
# Проверьте наличие:
docker --version        # Docker 20.10+
docker-compose --version # Docker Compose 2.0+
git --version           # Git для клонирования
```

**Установка (если нужно):**
```bash
# На Ubuntu/Debian:
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# На macOS:
brew install docker docker-compose
```

### 2. Supabase аккаунт (бесплатный)

1. Зарегистрируйтесь на https://supabase.com (бесплатно до 50К пользователей)
2. Создайте новый проект
3. Запомните данные:
   - Project URL (например: `https://xxxxx.supabase.co`)
   - API Key (Anon/Public)
   - JWT Secret

### 3. YouTube канал(ы)

1. Включите трансляции на YouTube Studio
2. Получите Stream Key для каждого канала
3. Запомните URL для RTMPS: `rtmps://a.rtmp.youtube.com/live2`

### Шаг 3: Создайте файлы конфигурации

**Backend** - создайте `.env` в корне проекта:

```bash
cat > .env << 'EOF'
# Supabase (замените на ваши данные)
SUPABASE_URL=https://ваш-проект.supabase.co
SUPABASE_KEY=ваш-anon-key
SUPABASE_JWT_SECRET=ваш-jwt-secret

# Encryption (замените на свой 32-символьный ключ)
ENCRYPTION_KEY=your-32-char-secret-key-12345678

# Paths (не менять)
UPLOAD_DIR=/app/uploads
STREAM_DIR=/app/streams

# FFmpeg (не менять)
FFMPEG_BIN=/usr/bin/ffmpeg
FFPROBE_BIN=/usr/bin/ffprobe
EOF
```

**Frontend** - создайте `frontend/.env.local`:

```bash
cat > frontend/.env.local << 'EOF'
# Supabase (замените на ваши данные)
NEXT_PUBLIC_SUPABASE_URL=https://ваш-проект.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш-anon-key

# API (не менять для локального запуска)
NEXT_PUBLIC_API_URL=http://localhost:8000/api
NEXT_PUBLIC_TUSD_URL=http://localhost:8080
EOF
```

## 📝 Первое использование

### 1. Загрузите видео

1. Перейдите в **Assets** (меню сверху)
2. Нажмите **"Upload Asset"**
3. Выберите видео файлы (.mp4, .mov, .mkv)
4. Дождитесь загрузки и валидации
5. Файлы с ✓ **Compatible** готовы к использованию

**Требования к видео:**
- Кодек видео: H.264
- Кодек аудио: AAC
- Формат пикселей: yuv420p
- GOP size: ≤ 2 секунды

**Если видео несовместимо:**
Используйте FFmpeg для конвертации:
```bash
ffmpeg -i input.mp4 -c:v libx264 -c:a aac -pix_fmt yuv420p -g 60 output.mp4
```

### 2. Создайте плейлист

1. Перейдите в **Playlists**
2. Нажмите **"Create Playlist"**
3. Введите название (например: "24/7 Music")
4. Добавьте видео из списка (только совместимые)
5. Включите **"Loop playlist"** для непрерывного стриминга
6. Нажмите **"Create"**

### 3. Добавьте YouTube канал

1. Перейдите в **Destinations**
2. Нажмите **"Add Destination"**
3. Введите:
   - **Name**: "Мой YouTube канал"
   - **RTMPS URL**: `rtmps://a.rtmp.youtube.com/live2` (по умолчанию)
   - **Stream Key**: ваш ключ с YouTube Studio
4. Нажмите **"Create"**

⚠️ **Stream Key шифруется и хранится безопасно!**

### 4. Создайте и запустите стрим

1. Перейдите в **Streams**
2. Нажмите **"Create Stream"**
3. Введите:
   - **Name**: "24/7 Stream"
   - **Playlist**: выберите созданный плейлист
   - **Destinations**: отметьте один или несколько каналов
4. Нажмите **"Create Stream"**
5. Нажмите кнопку **"Start"**
6. Откройте **"View Logs"** для мониторинга

### 5. Проверьте на YouTube

1. Откройте YouTube Studio → Прямые трансляции
2. Должна появиться ваша трансляция (статус: Live)
3. Проверьте качество изображения и звука

## 🔍 Мониторинг

### Dashboard

На главной странице вы видите:
- **CPU Usage** - загрузка процессора
- **Memory Usage** - использование RAM
- **Active Streams** - количество работающих стримов
- **Capacity** - сколько еще стримов можно запустить

Данные обновляются каждые 5 секунд.

### Логи стрима

В разделе **Streams** → кнопка **"View Logs"**:
- FFmpeg вывод в реальном времени
- Ошибки и предупреждения
- Статистика битрейта
- Обновление каждые 2 секунды

### Uptime

Для запущенных стримов отображается время работы (например: "2h 15m")

## 🔧 Решение проблем

### Стрим не запускается

1. Проверьте логи: **Streams** → **"View Logs"**
2. Убедитесь что:
   - Плейлист содержит совместимые видео
   - Stream Key правильный
   - YouTube трансляция включена
3. Проверьте подключение к интернету

### Загрузка файлов не работает

```bash
# Проверьте статус tusd
docker-compose ps tusd

# Если не запущен, перезапустите
docker-compose restart tusd
```

### "Incompatible" у всех видео

Конвертируйте видео в правильный формат:
```bash
ffmpeg -i input.mp4 \
  -c:v libx264 \
  -c:a aac \
  -pix_fmt yuv420p \
  -g 60 \
  -profile:v high \
  -level 4.1 \
  output.mp4
```

### Backend не запускается

```bash
# Посмотрите логи
docker-compose logs backend

# Проверьте .env файл
cat .env

# Пересоздайте контейнеры
docker-compose up -d --force-recreate backend
```

### Frontend не открывается

```bash
# Посмотрите логи
docker-compose logs frontend

# Проверьте .env.local
cat frontend/.env.local

# Пересоздайте контейнеры
docker-compose up -d --force-recreate frontend
```

## 💡 Советы

### Оптимизация для 24/7

1. **Используйте SSD** для хранения видео (быстрее чтение)
2. **Настройте автозапуск** Docker при перезагрузке сервера
3. **Включите мониторинг** на уровне ОС (htop, Prometheus)
4. **Настройте резервное копирование** базы данных
5. **Используйте UPS** для защиты от отключения электричества

### Множественные стримы

- Один плейлист → несколько каналов = **экономия CPU**
- Разные плейлисты → разные каналы = **больше контента**
- Проверяйте **Capacity** на Dashboard перед добавлением стримов

### Безопасность

- ✅ Stream Keys шифруются автоматически
- ✅ RLS защищает данные пользователей
- ✅ JWT токены для аутентификации
- 🔜 Настройте HTTPS для production (Caddy автоматически)
